## Batch-level defaults (compressed entry format — declared for reviewer ratification)
This is the corpus's most homogeneous family: signal-conditioned advisory rules with no enforcement substrate. **Unless an entry states otherwise, every rule in this batch carries:** `copyClass: advisory` · `detectorSource: llm_prompt` · `missingDataFallback: ignore_rule` · `guardrailBinding: none` · `secondaryEffects: []` · `predicateDefined: true`. Entries list only: `intendedMode`, `receiptTag`, `requiredSignals` with **status**, and notable flags. (MV vector: attack both the defaults and the compression — any entry whose omitted field should differ from the default is a finding.)

**Signal-status classes used below:** **[V]** = verified SIG row exists (SIG-001…008) · **[U]** = named signal with **no SIG row — availability unverified** · **[CAL]** = earnings-calendar class (real source, coverage-dependent — Batch 2 precedent).
**⚠ Structural finding (see Finding 2):** the fundamental family's sub-metrics are almost entirely **[U]**. Interim marking rule proposed for ratification: metadata entries may cite [U] signals *with the status disclosed inline*; compat cells may NOT cite them until a SIG row is minted (per the §5 binding rule). A single CC "fundamental signal inventory" read mints or refutes the lot.
