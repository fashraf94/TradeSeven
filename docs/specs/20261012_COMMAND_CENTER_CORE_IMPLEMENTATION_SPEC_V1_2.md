### 5.4 Dismissal, retry, cooldown, and orphan cleanup

P: Dismissal immediately closes the matching ceremony and releases its matching hold/stash. Created/existing and definitive refused terminals become acknowledged and return to idle with any owner/target cooldown retained separately; Enter/Open validates identity, epoch and document owner again immediately before navigation. Refused supports explicit Retry and applicable actions.
