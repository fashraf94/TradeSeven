# Build B spec V1.0 — Amendment J: founder rulings for B2.1, the screen pass (2026-10-22)

- **RJ-1 — Meetings on screen.**
  - A meeting's diagnosis is platform-composed text, built by the evaluator from a fixed template. It renders as an R7 quotation credited "— the platform", with the meeting's `createdAt`. Its numbers are exempt as quoted words.
  - Outcomes read **approved**, **rejected** or **expired**, with `resolvedBy` as stored.
  - The deadline is the stored `expiresAt`, shown as recorded.
  - Meetings are the owner's record and never proof (RE-5). The section says nothing about whether a meeting's proposal was right.
- **RJ-2 — A symbol with no series.**
  - When the tape records a reason, Deep dive says, for example: *"No chart for BTC: crypto is not charted."*
  - When it records none, Deep dive says: *"No chart was recorded for this symbol."*
  - The section's "complete" never appears beside it. The recorded prices at each check still show where the tape holds them.
- **RJ-3 — The result note when no check ran.** The note reads: *"no check ran this day, so no score was recorded"*. Otherwise the note names exactly the missing scores, as now. The platform's own completion message stays quoted as its words.
- **RJ-4 — Entry annotations.**
  - On the bought symbol, a swap annotation reads *"Entry · {time} · in for {sold symbol} · {maker}"*.
  - `{maker}` is "by the agent" or "by platform rule · {reason}".
  - The sold symbol keeps *"Exit · {time} · {maker}"*.
- **RJ-5 — A company name the directory lacks.** It reads *"Company name not on file"*. No name is guessed.
- **RJ-6 — The delay wording.** `evidenceOverlayNote` becomes:

  > *"A marker may sit off the bar line: the price the agent was shown came from a quote that runs about 15–20 minutes behind the bars, and the bars are not smoothed."*

  It claims no cause for any particular gap. The digits are an exempt fixed phrase, bound by copy key (A2F1-7).
- **RJ-7 — One coverage line on Glance.**
  - Glance shows one line, for example: *"Coverage · complete for every section"*, or *"Coverage · complete except: series (partial — 1 symbol not charted)"*.
  - Every count carries its class (D).
  - Sections that aren't complete are named with their stored reasons. Repeated "complete" lines are folded into this one.
  - The cards' unavailable-day count uses the same style: *"Recurrences · {n} days in this window could not be read"*.
- **RJ-8 — Set's link.**
  - With the day's stagnation rule on, Set reads *"You change the setting yourself; this card changes nothing."* and links *"Tempo dial · Forge workshop"*.
  - With it off, Set reads *"You change the setting yourself; this card changes nothing. No setting changes this situation for this archetype."*, with no link.
- **RJ-9 — Changes for cards-off players are declared.**
  - This pass changes the live v2 screen on purpose, through Part A and nothing else.
  - The cards-off goldens are re-captured at this build's head, and every difference from B2's goldens maps to a named Part A item.
  - With cards off, no card region renders, and the legacy screen is unchanged in every mode.
- **RJ-10 — Back after opening another battle.** Opening a recurrence's battle keeps the Film Room's back destination as it was. Back returns where the player first came from, not to the previous battle.
