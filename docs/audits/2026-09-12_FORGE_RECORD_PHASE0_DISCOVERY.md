## 5. Things you noticed that no question asked

Cited; not acted on.

1. **`provenance` is already a field, with a different type.** Rule docs carry a string enum (`firestore.rules:352-354`; `ruleDocFields.js:31`); bundle snapshots and the equip-time projection copy it (`forgeService.js:494`; `bundleRuleProjection.js:25`); the deploy-time projection drops it (`projectActiveRules.js:41-57`). The two `activeRules` projections therefore produce different objects — and different `equippedConfigHash` values — for the same equip state depending on whether equip-bundle or deploy last wrote `activeRules`.
2. **`archetype_default` already exists as a literal** (`traitEquip.js:73`; `StarterKit.jsx:484`; server `archetypeSeeding.js` via `buildSeedRuleDoc`) — the spec's enum value coincides with a live string on a different-typed field.
3. **Dimension materializer omits `provenance`** while every other rule writer emits it (`dimensionMapper.js:1051-1071` vs `ruleDocFields.js:31`) — a pre-existing drift the reconciler reads as "null = assumed tier".
4. **Dead read:** `src/utils/watchlistProvenance.js:24` branches on `watchlist.source === 'theme'`; `source: 'theme'` is written only to `watchlistSessions` (`api/forge/watchlist-dialogue.js:895` [agent]), never to `watchlists`.
5. **Unmounted Forge surfaces:** `ForgeLanding.jsx`, `ForgeScreen.jsx`, `AgentLearnedSection.jsx` (Q-10/Q-15); the `App.jsx:8609-8610` comment describes `ForgeLanding` as primary while `:8619` renders `ForgeWorkshop`.
6. **`agent.config.risk` is still read** (`agentBattleService.js:209`; `agentEvalPromptAssembly.js:755`; `resolvedAgentManifest.js:178`) although Thesis §8 LD-18 records the orphan field as removed.
7. **Stale comment:** `resolvedAgentManifest.js:15` says "ZERO READERS"; `agentEvalPromptAssembly.js:793-796` reads `compositionCompat`.
8. **The auto-debrief cron can mint Forge suggestions with no user present** (`agent-batch-review.js:372,385,439-457`) — the only gate is prompt prose. The same two writers append `agent.lessons[]`, which consolidation consumes (`agentConsolidationApply.js:119`); `forgeSuggestions[]` has no consumer and grows by `arrayUnion` without bound.

10. **Two other "provenance" vocabularies live nearby:** archetype birth provenance (`firestore.rules:53,250`; `change-archetype.js:259`) and Correlation-Lab group provenance (`src/components/Research/correlationGroup.js:151-203`).
