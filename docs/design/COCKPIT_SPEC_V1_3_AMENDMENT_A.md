# Cockpit Spec V1.3 — Amendment A (Build 0 rulings applied)

**Date:** 2026-09-24 · **Author:** Fable · **Applies to:** `docs/design/COCKPIT_SPEC_V1_3.md` (committed-blob SHA-256 `5a6a9a4e…a9939`, the pinned input of Build 0 PR #903). V1.3 stays as committed for the Build 0 record; this amendment states the clauses its rulings superseded. **Contract of record from this amendment on:** `CALL_RECORD_FIELD_CONTRACT_V1_4.md` (H1, H2).
**Source:** founder rulings A-1 and E-3 (build report §12), Astra's branch review `docs/audits/20260924_BUILD0_CALL_RECORDS_REVIEW.md` (BR-1–BR-6), the fixes in report §13. All are on `main` after PR #903.

| Spec clause | V1.3 said | Now (as built and reviewed) |
|---|---|---|
| **§3.6 provenance** | `provenance_unresolved` when "a hash exists without a watchlist" | **A-1 / contract H1:** an absent or `null` frozen `equippedWatchlist` → `agent_initiative`, `hypothesisRef: null`, the config hash ignored; `provenance_unresolved` only for a present-but-unusable snapshot (`snapshot_corrupt`, `config_hash_missing`); `hash_without_watchlist` retired |
| **§3.8 flips, `next_check`** | `observedAtMs > expiresAtMs` → `expired_unresolved` for every basis | **E-3 / BR-1 / contract H2:** for `next_check` only, the first check that *reaches* the still-open call with `observedAtMs ≥ expiresAtMs` judges it once inside its transaction — `hit` if the condition is met, else `expired_unresolved`; a judgment exists only when the transaction commits; no battle-level clock; other bases unchanged |
| **§3.8 `cronState.callFlips` shape** | `{ evalId, cursor, scanned, total, complete }` | **unchanged** — the interim `observedAtMs` field added under §12.2 was removed by BR-1 |
| **§3.4 gameplan rows (pending, created)** | "the set the deterministic pass examined" | **BR-2:** the examined set is every held name **only if the pass ran a price-scanning guardrail** (`stopLoss`, `trailingStop`, `profitTarget` with a numeric value); a sector-only, max-position-only or non-numeric pass freezes an **empty** set — expiry allowed, `hit` impossible; the adapter `passExaminesHeldPrices` mirrors the fenced helper's preconditions and never edits it |
| **§3.1 descriptions (model-visible)** | "descriptions that teach the model when to declare" | **BR-3:** the block and every field state the records are **stored only** — not shown to the player, no response requested, no trade executed or scheduled, not supplied to a later check, no change to this check's decision or `anticipationCandidates`; `said` is a conditional, presentation-only sentence; a test pins the invisible-recipient language; the exact text needs Astra's confirmation before shadow (fenced-class, coordinated review) |
| **§2 mode resolution** | "once per handler invocation" | **clarified:** once per battle check, at that check's context creation; the shipped flag is a static module constant, so the two readings coincide today |
| **§3.13 shadow read** | as written | add: truncation events now measured against a schema of 4,154 chars (≈ 1,039–1,385 tokens); the largest fixture request is 10,132 of 12,000 tokens; the real `countTokens` measurement is a pre-flip gate |
| **§4 Build 1 sweep** | expiry backstop on `expiresAt` | **H2 obligation:** the worker must honor the `next_check` judgment opportunity — it expires a `next_check` call only under a separately agreed unobserved-expiry policy, never mechanically at its slot; other bases sweep on `expiresAt` |

**Not changed by this amendment:** every other clause of V1.3 §3, the three-kind family, the phase wire, the companion receipt, the composition rows, the budget rule.
